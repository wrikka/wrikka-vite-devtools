How a change gets made

  1. 1 Open the hub. The dock seeds itself as a left edge rail; every panel is an iframe owned by the plugin.
  2. 2 Pick a node. The in-page pill targets an element, a component, or the whole page and names the route.
  3. 3 Comment, then let the agent run. The Inbox streams the run; the same store answers MCP clients.

Mount it

// vite.config.ts
useWrikkaViteDevtools({
  plugins: 'all',
  dock: { mode: 'edge', position: 'left' },
  auth: false,
})
Place the plugin before framework plugins that transform HTML or the SSR entry.
