Usage

What the plugin gives you and where each piece lives.

In the page

  • Comment pill (bottom-left) — click any element or route, write a note, submit. The run streams in the hub's Comments panel.
  • Chat pill — opens a docked chat on the left that pushes the whole page right. Expand for fullscreen; prompts go straight to the agent.

In the hub

  • Dock rail — /__devtools/ lists every panel; Home is the landing surface.
  • MCP endpoint — POST /__devtools/__mcp exposes every RPC as a tool (wrikka-vite-devtools_*).

Options that matter

useWrikkaViteDevtools({
  plugins: 'all',        // or a subset of plugin keys
  overlay: true,         // in-page pill + chat (default on)
  auth: false,           // disable OTP — localhost only
  role: 'operator',      // or 'viewer' for read-only
  agent: { autoRun: true },
  dock: { mode: 'edge', position: 'left' },
})
Full option and RPC reference lives in USAGE.md in the repo.
