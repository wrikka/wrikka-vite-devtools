Get started

Three steps from a Vite app to a working devtools hub.

  1. 1
    Install the plugin 
    bun add -D wrikka-vite-devtools
    Any Vite 6+ app works. This page is itself running the plugin — the pill in the bottom-left corner is live.
  2. 2
    Register it first in vite.config.ts 
    import { useWrikkaViteDevtools } from 'wrikka-vite-devtools/vite'

export default defineConfig({
  plugins: [
    useWrikkaViteDevtools({
      plugins: 'all',
      dock: { mode: 'edge', position: 'left' },
      auth: false, // localhost only
    }),
    // …framework plugins after this one
  ],
})
  3. 3
    Run dev and open the hub 
    bun run dev
# → http://localhost:5173/__devtools/
    The dock seeds itself as a left edge rail. Click the pill on any page to annotate it, or open the chat to hand work to your agent CLI.
Browser extension (optional) packages/browser-extension detects whether a local page has the plugin and offers setup steps when it doesn't. Build it with bun run build inside that folder, then load dist/ as an unpacked extension.
